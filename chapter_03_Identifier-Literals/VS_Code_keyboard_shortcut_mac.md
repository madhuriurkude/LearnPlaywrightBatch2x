# VS Code Keyboard Shortcuts - Mac

| Action | Shortcut |
|---|---|
| Command Palette | `Cmd + Shift + P` |
| Quick Open (Go to File) | `Cmd + P` |
| New File | `Cmd + N` |
| Open File | `Cmd + O` |
| Save | `Cmd + S` |
| Save All | `Cmd + K` then `S` |
| Close Editor | `Cmd + W` |
| Close All Editors | `Cmd + K` then `W` |
| Undo | `Cmd + Z` |
| Redo | `Cmd + Shift + Z` |
| Cut | `Cmd + X` |
| Copy | `Cmd + C` |
| Paste | `Cmd + V` |
| Find | `Cmd + F` |
| Replace | `Cmd + H` |
| Find in Files | `Cmd + Shift + F` |
| Replace in Files | `Cmd + Shift + H` |
| Go to Line | `Ctrl + G` |
| Go to Definition | `F12` |
| Go Back | `Ctrl + -` |
| Go Forward | `Ctrl + Shift + -` |
| Toggle Sidebar | `Cmd + B` |
| Toggle Terminal | `` Ctrl + ` `` |
| Toggle Word Wrap | `Option + Z` |
| Comment Line | `Cmd + /` |
| Comment Block | `Shift + Option + A` |
| Format Document | `Shift + Option + F` |
| Duplicate Line | `Shift + Option + ↓` |
| Move Line Up | `Option + ↑` |
| Move Line Down | `Option + ↓` |
| Delete Line | `Cmd + Shift + K` |
| Add Cursor Above | `Cmd + Option + ↑` |
| Add Cursor Below | `Cmd + Option + ↓` |
| Select Current Line | `Cmd + L` |
| Select All Occurrences | `Cmd + Shift + L` |
| Start Debugging | `F5` |
| Toggle Breakpoint | `F9` |
| Step Over | `F10` |
| Step Into | `F11` |
| Open Settings | `Cmd + ,` |
| Open Keyboard Shortcuts | `Cmd + K` then `Cmd + S` |
