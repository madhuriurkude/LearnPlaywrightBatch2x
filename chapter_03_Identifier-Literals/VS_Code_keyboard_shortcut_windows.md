# VS Code Keyboard Shortcuts - Windows

| Action | Shortcut |
|---|---|
| Command Palette | `Ctrl + Shift + P` |
| Quick Open (Go to File) | `Ctrl + P` |
| New File | `Ctrl + N` |
| Open File | `Ctrl + O` |
| Save | `Ctrl + S` |
| Save All | `Ctrl + K` then `S` |
| Close Editor | `Ctrl + W` |
| Close All Editors | `Ctrl + K` then `W` |
| Undo | `Ctrl + Z` |
| Redo | `Ctrl + Y` |
| Cut | `Ctrl + X` |
| Copy | `Ctrl + C` |
| Paste | `Ctrl + V` |
| Find | `Ctrl + F` |
| Replace | `Ctrl + H` |
| Find in Files | `Ctrl + Shift + F` |
| Replace in Files | `Ctrl + Shift + H` |
| Go to Line | `Ctrl + G` |
| Go to Definition | `F12` |
| Go Back | `Alt + ←` |
| Go Forward | `Alt + →` |
| Toggle Sidebar | `Ctrl + B` |
| Toggle Terminal | `` Ctrl + ` `` |
| Toggle Word Wrap | `Alt + Z` |
| Comment Line | `Ctrl + /` |
| Comment Block | `Shift + Alt + A` |
| Format Document | `Shift + Alt + F` |
| Duplicate Line | `Shift + Alt + ↓` |
| Move Line Up | `Alt + ↑` |
| Move Line Down | `Alt + ↓` |
| Delete Line | `Ctrl + Shift + K` |
| Add Cursor Above | `Ctrl + Alt + ↑` |
| Add Cursor Below | `Ctrl + Alt + ↓` |
| Select Current Line | `Ctrl + L` |
| Select All Occurrences | `Ctrl + Shift + L` |
| Start Debugging | `F5` |
| Toggle Breakpoint | `F9` |
| Step Over | `F10` |
| Step Into | `F11` |
| Open Settings | `Ctrl + ,` |
| Open Keyboard Shortcuts | `Ctrl + K` then `Ctrl + S` |
