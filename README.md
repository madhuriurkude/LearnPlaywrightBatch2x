## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/madhuriurkude/LearnPlaywrightBatch2x.git
   ```

2. Open in VS Code and explore the chapters in order.

3. Run JavaScript files using Node.js:
   ```bash
   node chapter_01_Basics/01_Basics.js
   ```

## 📚 Chapters Overview

| Chapter | Topic | Files |
|---------|-------|-------|
| 1 | JavaScript Basics | `01_Basics.js` to `04_HotCode.js` |

- [Node.js](https://nodejs.org/) installed

- JavaScript fundamentals and syntax
